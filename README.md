# Sortyd

Sortyd is a free habit and planning app built to help people create better routines and more structured days.

## Features

Daily and weekly planning, habit tracking, reminders, progress analytics, AI assisted planning and coaching, and Apple Health integration on supported Apple devices.

The project includes English, Arabic, Spanish, and Chinese localization, with work across iOS, macOS, and Android.

## Repository structure

`ios/` contains the Apple platform application code.

`android/` contains the Android application code.

`cloudflare/sortyd-proxy/` contains the backend worker.

`supabase/migrations/` contains database migrations.

`website/` contains the website source.

`tests/` and `docs/` contain supporting tests and project documentation.

## Development

Platform specific build and setup instructions are being prepared. A local checkout alone does not configure production services. Use your own service projects and environment configuration. Keep private credentials outside version control.

## Contributions

Issues and improvement proposals are welcome . Please describe the platform, expected behavior, and steps to reproduce a bug. Never include account tokens, personal health records, or other private user data in an issue.
